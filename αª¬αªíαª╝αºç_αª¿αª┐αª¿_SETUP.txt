কার্টুন বট (Sumonsham/hindi-story-bot) — সম্পূর্ণ আপডেট (২৩ নভেম্বর ২০২৬, রাত)
==========================================================================

নতুন সময়সূচি (কোন কাজ কখন, আর কেন)
------------------------------------
রাত ১১:০০  পরের দিনের তিনটে গল্প লেখা (সকাল ৭টা, দুপুর ১টা, সন্ধ্যা ৭টা)
           প্রতিটা গল্প ঠিক তার নিজের দিনের প্রোগ্রাম, সিরিজের পর্ব, Telegram-এ পাঠানো আপনার গল্প
           আর দর্শকদের ভোট মেনে লেখা হয়। কিছু পোস্ট হয় না।
রাত ২:০০  শুধু নতুন চরিত্র তৈরি (হরর বটের মতোই দুজন সহকারী; নিচে দেখুন)
রাত ২:৩০  সকাল ৭টার ভিডিওর run
সকাল ৮:৩০  দুপুর ১টার ভিডিওর run
দুপুর ২:৩০  সন্ধ্যা ৭টার ভিডিওর run

কেন এই সময়: অ্যানিমেশন আঁকা হয় ভয়েসের সময় মেপে, তাই ভয়েসের পরে। প্রতিটা run পোস্টের প্রায়
সাড়ে চার ঘণ্টা আগে রাখলাম, যাতে ভয়েস আর পুরো অ্যানিমেশন সময়মতো শেষ হয়।
গল্প আগের রাতেই লেখা থাকায় run-এর সময়টা পুরো ভয়েস আর অ্যানিমেশনে যাবে।
সকালের ভিডিও এখন ৭টায়। ৮টায় ফেরাতে চাইলে: Settings > Variables > MORNING_HOUR = 8,
আর cron-job.org-এ সকালের job ৩:৩০-এ দিন।

রাত ২টোর run কী করে (শুধু এটুকুই)
------------------------------------
১) গল্প-পড়ার সহকারী (Story Scout)
   রাত ১১টায় লেখা তিনটে গল্প পড়ে খুঁজে দেখে কোন চরিত্র লাইব্রেরিতে নেই। গোপাল, আকবর-বীরবল,
   দেবদেবী, ভুতু, টুকাইয়ের মতো স্থায়ী চরিত্র আগে থেকেই আছে। নতুন জন্তু বা নতুন মানুষ থাকলে
   তার পুরো বিবরণ লিখে দেয়।
২) চরিত্র-তৈরির সহকারী (Character Asset Builder)
   ওই বিবরণ দেখে চরিত্র বানায়, এঁকে পরীক্ষা করে, লাইব্রেরিতে (assets/tvtoon_library.json) স্থায়ীভাবে রাখে।
ভিডিওর run চরিত্র এখান থেকেই নেয়।

ভয়েস: এখন সবসময় Gemini (নতুন)
----------------------------------
• Microsoft (edge-tts) ভয়েস পুরো বাদ দেওয়া হয়েছে। এখন কোথাও কোনো লাইনে Microsoft ভয়েস আসা সম্ভব নয়।
• বিনামূল্যের GitHub ভয়েস মডেলও (Parler) বাদ, সেটা আর install-ও হয় না। ফলে প্রতিটা run দ্রুত শুরু হয়।
• প্রতিটা চরিত্রের নিজের Gemini ভয়েস থাকবে, মেয়েদের মেয়ের গলা।
• Gemini-র দিনের বিনামূল্যের ভাগ শেষ হলে, আপনার আগে অনুমোদন দেওয়া Chirp 3 HD-র একই নামের ভয়েস নেবে।
  সেটাও না চাইলে: Settings > Variables > CARTOON_CHIRP = 0
• Gemini (বা Chirp) কোনোটাই না পেলে অন্য কোনো ভয়েসে ভিডিও বানাবে না। Telegram-এ জানাবে,
  আর পরের run আবার চেষ্টা করবে।
• দরকার শুধু এই repo-র নিজের GEMINI_TTS_KEY secret (এক বটে একটাই key, যেমন নিয়ম)।
  এটা আগে থেকেই আছে, নতুন কিছু করতে হবে না।

আর যা যা ঠিক হল
------------------
• এক লাইন দু'বার বা তিনবার বলা: প্রতিটা ভয়েস পরীক্ষা হয়, পুনরাবৃত্তি কেটে বাদ যায়।
• আরও জোরালো গল্প
  লেখকের জন্য নতুন নিয়ম:
  - শুরুতেই পরিষ্কার একটা চাওয়া বা সমস্যা;
  - প্রতিটা দৃশ্যে নতুন কিছু;
  - ধাপে ধাপে বাড়া সমস্যা আর বুদ্ধির সমাধান;
  - শিক্ষাটা কাজের মধ্যে দিয়ে দেখানো;
  - কোনো কথা দু'বার নয়।
  প্রতিটা লাইনের সঙ্গে চরিত্রটা কী করছে ("action") সেটাও লেখা হয়।
• হাত আর ব্যাকগ্রাউন্ড উন্নত হয়েছে, হরর বটের মতোই।
• গল্পের ছবি, হুক, লুমি দিদির অংশ আর ৯:১৬ ভার্সন সব কার্টুনে, আগের আপডেটের মতো।

GitHub-এ কী কী তুলবেন
-----------------------
A) Add file > Upload files। এই zip-এর tvtoon ফোল্ডার (পুরোটা), main.py আর extras.py টেনে দিন। তারপর Commit changes।
B) .github/workflows/daily-story.yml
   GitHub-এ ফাইলটা খুলুন > পেন্সিল চিহ্ন > সব মুছে এই zip-এর daily-story.yml-এর পুরোটা পেস্ট করুন > Commit।

cron-job.org-এ কী বদলাবেন (কার্টুন)
------------------------------------
URL আর Header আগের কার্টুন job-এর মতোই থাকবে:
১) নতুন job: রাত 23:00 (Asia/Kolkata)
   Request body: {"ref":"main","inputs":{"mode":"write"}}
২) নতুন job: রাত 02:00
   Request body: {"ref":"main","inputs":{"mode":"assets"}}
৩) সকালের ভিডিওর job (এখন 03:30): সময় বদলে 02:30 করুন
   Request body আগের মতোই: {"ref":"main","inputs":{"mode":"auto"}}
৪) দুপুরের job: 08:30 (আগের মতোই, বদলাতে হবে না)
৫) সন্ধ্যার job: 14:30 (আগের মতোই, বদলাতে হবে না)
নতুন job বানানোর সহজ উপায়: আগের কার্টুন job খুলে "Clone" করুন, তারপর শুধু সময় আর body বদলান।
